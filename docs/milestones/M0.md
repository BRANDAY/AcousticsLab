## Plan

1. Project files written by hand from the engine's `TP_Blank` template (no editor wizard): `AcousticsLab.uproject`, `Source/AcousticsLab*.Target.cs` (BuildSettingsVersion V7, include order Unreal5_8), modules `AcousticsCore` (Core only) and `AcousticsLab` (game).
2. Config: `DefaultEngine.ini` (default map `Level_MainMenu`, global game mode `AAcousticsGameMode`, DX12, 48 kHz audio), `DefaultGame.ini`, `DefaultInput.ini` copied from the template (Enhanced Input classes), empty `DefaultEditor.ini`.
3. Framework (`Source/AcousticsLab/*/Framework/`): `AAcousticsGameMode` (spectator-only in the menu level), `AAcousticsPlayerController` (Enhanced Input built in C++: WASD/arrows, mouse look, Q/E up-down, Esc → menu, keys 1–6 → A/B variant), `AAcousticsExplorerPawn` (flying first-person camera), `AAcousticsHUD` (level / mode / variant line).
4. `Levels/`: `AcousticsLevels` (map names, URL `mode` option), `ALevelSetupActor` (`EAcousticLevelKind`, display name).
5. `UI/UMainMenuWidget`: SPEC §0 tree, built in C++ (`RebuildWidget`) when no Blueprint layout is present; `BindWidgetOptional` slots `MenuBox` / `TitleText` / `StatusText` for a future `WBP_MainMenu`.
6. Placeholder maps `/Game/Maps/Level_*` created by `Tools/Editor/create_placeholder_levels.py` (headless python commandlet) with a `LevelSetupActor`, a `PlayerStart` and a text sign.
7. `AcousticsCore`: module, `LogAcoustics`, `AcousticsConstants.h` (`NumBands = 1`, c, receiver radius, histogram defaults), smoke test `AcousticsLab.Core.Smoke.Constants`.
8. Build editor target, run tests, commit `M0: project skeleton`.

## Deviations from SPEC / PROMPTS

- The project was written by hand from the engine's `TP_Blank` template instead of the editor's New Project wizard (same files, same UBT settings).
- No Blueprint layouts yet: `WBP_MainMenu` under `Content/UI/` needs the editor UI, so M0 builds the menu in C++ and leaves `BindWidgetOptional` hooks. To be added with the HUD widgets (M2/M3).
- Input actions and the mapping context are created at runtime in C++ (`AAcousticsPlayerController::BuildInputAssets`) instead of `IA_*` / `IMC_*` DataAssets. Can be migrated to assets later without touching the bindings.
- Game framework classes live in `Source/AcousticsLab/{Public,Private}/Framework/`, a folder the SPEC §3.2 list does not have.
- Menu items 1.3 (benchmark), 1.4 (hybrid) and 3 (Compare) open `Level_Shoebox` with `?mode=Benchmark|Hybrid|Compare`; the panels themselves come in M7/M8. 1.1 has two entries (Shoebox, Amphitheatre).
- `SteamAudio` / `AudioTracing` plugins are not in the `.uproject` yet (M9); the TODO is in `docs/ENV.md` because JSON has no comments.
- Build note: with any Unreal editor running with Live Coding on, `Build.bat` refuses to build ("Unable to build while Live Coding is active"); `-NoHotReloadFromIDE` bypasses the check safely while this project is not open in that editor.

## Verify in the editor

1. Open `AcousticsLab.uproject` (Epic Launcher → project browser → Browse, or double-click). It opens on `Level_MainMenu`.
2. Play with **Standalone Game** (Play dropdown → Standalone Game): in PIE the editor itself consumes Esc to stop play, so the Esc → menu path is only visible standalone. Expected: dark backdrop, "ACOUSTICS LAB", sections 1–3 and Quit.
3. Click any entry: the placeholder level loads (floor, sky, a sign with the level name), the HUD top-left shows `Level_… | mode: … | A/B variant: 0`. WASD + mouse fly, Q/E move down/up, keys 1–6 change the variant number, Esc returns to the menu. Quit closes the game.
4. Tests: Tools → Session Frontend → Automation → filter `AcousticsLab` → Start Tests; `AcousticsLab.Core.Smoke.Constants` must pass. Headless: the test command in `CLAUDE.md`.
